# Changelog - LingeshMart

All notable changes to this project will be documented in this file.

## [v1.1.0] - 2026-10-03
### Added
- Phase 3 AI Assistant Chatbot widget (`/api/v1/chat`) with `GeminiChatProvider` and `MockChatProvider`.
- Per-session rate limiting (10 msg/min) and response caching.

## [v1.0.0] - 2026-10-03
### Added
- Complete Multi-Seller E-Commerce Marketplace MVP (F1-F8, O1-O3).
- User authentication & role management (Buyer, Seller, Admin).
- Seller Product Management & Analytics Sales Dashboard.
- Shopping Cart, Mock Payment Checkout, and Order Status Workflow.
- Product Reviews & Star Ratings for completed orders.
- Wishlist / Save-for-later feature.
- REST API v1 endpoints (`/api/v1/health`, `/api/v1/products`, `/api/v1/chat`).
